GraceSlide 사용법

1 API 키 입력 (최초 1회)

AI 기능을 쓰려면 Google AI Studio에서 무료로 발급받은 Gemini API 키가 필요합니다.

  1. aistudio.google.com 접속 → Google 계정 로그인
  2. "Get API Key" → "Create API Key" 클릭
  3. 발급된 키를 복사해 상단 입력창에 붙여넣고 "키 확인" 클릭

※ 키는 이 브라우저에만 저장되며, 무료 사용량 내에서 추가 비용 없이 쓸 수 있습니다.

2 설교 정보 입력

설교 제목과 설교자를 입력하면 첫 장(타이틀 슬라이드)이 자동으로 만들어집니다.

3 성경구절 슬라이드 만들기

설교 원고를 붙여넣고 "성경구절 자동 추출" 버튼을 누르면 AI가 구절을 찾아 슬라이드를 만듭니다. 3절 이상인 구절은 자동으로 2절씩 나눠줍니다.

4 슬라이드 다듬기

상단 도구모음에서 성경 폰트(명조/고딕/나눔명조/나눔고딕), 정렬(왼쪽/가운데/오른쪽), 성경 레이아웃(전체 텍스트/왼쪽 텍스트+오른쪽 이미지칸/왼쪽 이미지칸+오른쪽 텍스트)을 바꿀 수 있습니다. 제목 뱃지·장절·본문은 서로 다른 색으로 표시됩니다. 이미지칸에는 '그림 불러오기'로 불러온 그림이 들어갑니다. 그림은 불러온 그 슬라이드에만 적용되고 다른 슬라이드에는 적용되지 않습니다. 분할 레이아웃을 선택하면 이미지칸에 표시되고, 이미지칸을 클릭해도 그림을 바꿀 수 있습니다. 이미지칸 사진은 기본으로 전체가 보이게 표시되며, '사진 작게/크게' 버튼으로 10%씩 자유롭게 줄이고 키울 수 있습니다.

  • 썸네일 드래그로 순서 변경, ✕ 삭제, 복사 버튼으로 복제
  • 연필 버튼으로 말씀 내용 직접 수정
  • 상단 A 버튼으로 글자 크기 조절 (끝없이 작게/크게, 보통보다 N단계로 표시)
  • 사진 작게/크게 버튼으로 이미지칸 사진 크기 조절 (10%씩, 크게는 제한 없음)
  • Ctrl+Z로 실행 취소, Ctrl+Y로 다시 실행
  • 작업은 자동으로 저장됩니다 (새로고침해도 유지)

5 저장하기

  • PPTX 다운로드: PowerPoint에서 열리는 파일 (텍스트 수정 가능)
  • PDF 저장: 인쇄 창에서 "PDF로 저장" 선택 (화면 비율과 같은 비율로 저장)
  • 이미지 저장: 슬라이드에 마우스를 올리면 개별 이미지 저장 가능
